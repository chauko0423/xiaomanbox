# Lineage and limits

Public source/evidence are machine-path/device-identifier derivatives with original and public SHA256 lineage. Original configurations and byte hashes are retained; original manifests are provenance and require rebinding for fresh execution. Published manifests certify the public bytes, not undistributed weights or original private bytes. A repository commit pin is an immutable address, not an external timestamp proving pre-exposure freeze.

The v6 original frozen aggregate failed a sample-boundary audit; the post hoc disclosure remains separate and does not repair that original audit. The v9 configuration contains a stale local-time metadata field; its UTC field and first-attempt clock anchor are separately disclosed without changing original configuration bytes. v7 raw dialogues that could contain proprietary SDK excerpts are omitted; numeric scoring/resource/effective-mode records remain. These omissions are explicit in provenance.

The tasks are selected public defects with disclosed localization and finite developer suites. Qualification can adapt the execution environment while leaving original test assertions intact. Express uses official Node 0.10.48 and restored declared cookie-session dependencies; Hexo/Hessian use Node 8.17.0. Hessian assertion support uses should10.0.0 in the shared fixed environment. Hessian 8's upstream reference adds Long3 as a production dependency; the model receives the immutable buggy package declaration and may edit only lib/utils.js. This shared reference environment is not a claim that all upstream package declarations are identical. Hexo aliases already included in the dependency package were used; no v10 installation bootstrap script ran. Final numeric eligibility preceded task generation, and excluded Express 4/Hexo 6 reference failures are retained.

Codex AI assistance supported study planning, task/acceptance preparation, protocol/audit code, orchestration, descriptive analysis and documentation. This differs from the separately hash-identified local model being evaluated. AI-assisted checking is not independent human review; the release does not assert all-author approval of generated code or interpretations.

Original hidden suites are independently authored project tests; they are not independent human review. Public pretraining exposure is unknown. One model, one workstation, six related defects and two same-seed repetitions cannot establish broad reliability, cross-model gains, pure quantization causality or universal correctness. v7 UE failures remain part of the record. Offline auditing, reference qualification and actual model repair are separately labeled.
