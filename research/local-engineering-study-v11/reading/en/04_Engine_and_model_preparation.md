# Engine and model preparation

engine_source_manifest.json binds the 1609-file private source inventory to the freshly built text-only engine. The public engine_source directory contains 1430 unchanged build-source files; 179 unrelated evaluation corpus/media/model-card files are omitted and individually listed. This is an exact-byte build-source subset, not redistribution of the complete private snapshot. Original Apache2 and third-party licenses remain.

Build settings are Release, Ninja, sm120a, NINFER_ENABLE_VISION=OFF, NINFER_BUILD_APPS=ON, BUILD_TESTING=OFF, NINFER_BUILD_BENCHMARKS=OFF and NINFER_BUILD_LINK_SMOKE=OFF. MSVC 14.44.35207 and CUDA compiler 13.3.33 were recorded. engine_build contains deidentified original configure/build request metadata. Use a fresh build directory and reader-provided compiler/runtime paths; identical binary hashes across independent toolchains are not promised. The older engine's exact build source remains unattested.

model_preparation contains the recorded CPU bridge and common groupwise conversion recipes, requiring path rebinding and separately obtained checkpoints. The U8 packed-weight naming bridge preserves payloads; FP8 scale broadcasting to BF16 rounds and is not bit-lossless. local_38 frontend normalization derives added_tokens_decoder from actual tokenizer.json, explicitly disables BOS and normalizes pad metadata from im_end to endoftext. EOS is unchanged; the bound chat template does not consume pad_token on single unpadded requests. All 771 local_38 tensor payloads are unchanged by that frontend revision. The two formal artifacts themselves differ in all 771 tensor payloads and belong to one existing architecture. Whole-artifact comparison is not a quantization-only causal experiment.
