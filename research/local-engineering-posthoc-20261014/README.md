# Local engineering study post hoc supplement

This deposit adds candidate-informed finite semantic checks and deidentified historical deployment excerpts. It preserves the frozen original60-attempt study: 6 strict completions and 15 original-full-suite passes. There are zero new model requests. Author declarations, independent human review and journal submission remain incomplete. The original immutable study is at https://github.com/chauko0423/xiaomanbox/tree/ba261bdcb602af198941a3868e476a14a791559e/research/local-engineering-study-v11 .

Read `reading/en` or `reading/zh` for matching explanations. Run `python verify_supplement.py --self-test` after extraction. The verifier checks derivative-byte hashes, all 15 eligibility/source bindings, reference and buggy controls, complete case sequences and finite result counts. Its negative controls test deliberate hash, selection, case, result and historical-evidence mutations. Hash integrity is not independent semantic or historical-performance validation.

To replay the 58 distinct supplemental cases on all 23 source variants, obtain the original public full-reference projects, licensed Node 0.10.28/6.17.1/8.17.0 executables and matching dependencies from the original deposit recipes. Run `python replay_semantic.py --reference-root PATH --dependencies-root PATH --runtime-root PATH --work-root EMPTY_PATH`. The reference root contains task-ID directories; the dependency root contains case-name/node_modules directories. No model or GPU is used. Hashes bind the replay to frozen runtimes and editable files; compatible but different assets require a separately labeled exploratory run.

Historical sources are partial redacted derivatives with private-origin SHA256, not complete raw performance traces. No cross-machine task replication or hardware-only throughput effect is established. Performance values remain report-attributed. Original manuscripts, author details, operational messages, machine addresses, weights and executables are excluded.
